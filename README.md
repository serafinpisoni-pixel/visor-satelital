# Visor satelital Sentinel-2

Página web para ver imágenes Sentinel-2 de cualquier lote desde el celular: color real (RGB) y NDVI, con exportación a JPG.

**Abrir:** https://serafinpisoni-pixel.github.io/visor-satelital/

- Área: ubicación actual, punto con radio, polígono dibujado o archivo KML / KMZ / GeoJSON / shapefile (.zip).
- Fechas: búsqueda por rango y nubosidad, o «Última limpia» (la escena más reciente sin nubes sobre el área).
- Todo se procesa en el navegador. No necesita cuenta ni servidor.

En el iPhone: abrir el link en Safari, tocar Compartir › «Agregar a inicio».

Datos: Copernicus Sentinel-2 L2A colección 1 (ESA), servidos como Cloud-Optimized GeoTIFF en AWS Open Data y catalogados por Earth Search de Element 84. Contiene datos modificados de Copernicus Sentinel.
